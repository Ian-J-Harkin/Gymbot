Title: Epic 7, Story 1: Build Standalone Widget with Preact

Goal: To create a lightweight, embeddable chat widget that can be easily added to any website.

User Story: As a developer, I want to bundle the chat widget into a single JavaScript file so that gym owners can easily embed it with a simple script tag.

Requirements:
1. Initialize a Preact + TypeScript project for the widget.
2. Implement a floating launcher button at the bottom right.
3. Implement a primary chat window that opens on click.
4. Support configurable primary color via the `/widget/config` endpoint.
5. Implement message streaming support using the backend's SSE format.
6. Bundle the entire application into a single `gymbot.min.js` file using Vite.

Acceptance Criteria:
- The widget loads correctly on a test HTML page using a single `<script>` tag.
- The widget fetches its configuration (color) using the provided API key.
- The chat interface is mobile-responsive.
- Message interaction (typing and receiving) works as expected.

Technical Context:
- Build Tool: Vite
- Framework: Preact
- Output: Single JS file with inlined CSS (optional but preferred for ease of install)
