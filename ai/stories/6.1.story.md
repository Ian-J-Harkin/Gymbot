Title: Epic 6, Story 1: Display Explanation Metadata in Widget

Goal: To allow users to see the "Why did I say this?" metadata provided by the explanation layer.

User Story: As a website visitor, I want to understand how the chatbot arrived at its answer so that I can trust the information provided.

Requirements:
1. Parse the `explanation` object received from the SSE stream in the frontend widget.
2. Provide a UI element (e.g., an "Info" icon or a "Why?" toggle) for each AI message that has explanation metadata.
3. Display the details from the metadata:
   - AI Provider and Model used.
   - Context used (e.g., "Full FAQ").
   - Response time.
4. The disclosure of this information should be clean and not clutter the main chat interface.

Acceptance Criteria:
- The widget successfully receives and stores the `explanation` object from the `/widget/chat` SSE stream.
- A "View Details" or "Why?" button appears for AI messages.
- Clicking the button reveals a modal or expandable area with the explanation details.

Technical Context:
- Frontend: Preact (fitbot-widget)
- Backend: NestJS /widget/chat (already yielding { explanation })
- Component: ExplanationDetails.tsx
