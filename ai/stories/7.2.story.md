Title: Epic 7, Story 2: Widget Installation Documentation for End-Users

Goal: To provide clear, non-technical instructions for gym owners to install and verify the FitBot widget.

User Story: As a gym owner, I want easy-to-follow instructions so that I can install the chat widget on my website without needing a developer.

Requirements:
1. Create a "Getting Started" guide or Installation Manual.
2. Provide the exact script snippet required for embed.
3. Detail how to use the FitBot API key within the script tag.
4. List sensible default settings so users know what to expect out-of-the-box.
5. Provide a step-by-step testing plan to verify functionality (icon display, window opening, message streaming).
6. Include a simple troubleshooting table for common setup errors.

Acceptance Criteria:
- Documentation exists in a readable format (e.g., Markdown).
- Instructions are clear and do not require technical expertise.
- All configuration attributes (like `data-api-key`) are explained.
- A testing checklist is provided.

Technical Context:
- Target Audience: Non-technical Gym Owners
- Filename: WIDGET_INSTALLATION_GUIDE.md
